# Theme migration — status & checklist

Custom Jekyll theme built from scratch (no theme gem) on the `new-theme` branch.
This replaces the Chirpy theme while keeping every existing post.

## What's done

- **Theme skeleton**: `_layouts/`, `_includes/`, `_sass/`, `assets/css/main.scss`,
  `assets/js/` (theme toggle, code copy, TOC, Pagefind search).
- **Home** (`/`): hero + latest posts + featured projects.
- **Blog** (`/blog/`): paginated REA-style list (jekyll-paginate-v2).
- **Projects**: `_projects/` collection + `/projects/`.
- **About** (`/about/`) and **authors** (`/about/author/<slug>/`) from `_data/authors.yml`.
- **Tags / categories / yearly archive** pages, generated by `_plugins/generate-archives.rb`.
- **Takeaway** callout (front matter `takeaway:`) and sticky **"In this article" TOC**.
- **Search** (Pagefind), **dark mode**, **code copy**, **reading time**, **related posts**,
  **series** (`series:` front matter), **giscus comments**, **share buttons**.
- **SEO**: jekyll-seo-tag, sitemap, Atom feed, OG images (from existing `image.path`).
- **Redirects**: jekyll-redirect-from + a styled `_layouts/redirect.html`.
- **Extras**: `/uses/`, `/now/`, `/404.html`.
- **CI**: `.github/workflows/pages-deploy.yml` now runs Pagefind after `jekyll build`.

## Chirpy-syntax audit result

Across all 285 posts: **0** `{: .prompt-* }` callouts, **0** `{: .shadow/light/dark }`
image modifiers, **0** `pin:`/`toc:`/`redirect_from` keys. Only `image:` (284 posts),
`categories:` (284) and `tags:` (224) are used, and those are all supported by this theme.
No bulk post edits needed.
