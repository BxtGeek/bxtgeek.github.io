## FAQ

### What is FileRun?

FileRun is a self-hosted file sharing and management software that allows users to securely share and access files and folders from any device with a web browser.

### What are the main features of FileRun?

FileRun's main features include file and folder management, user and group management, file sharing and collaboration, and access control and security.

### How can I install FileRun?

FileRun can be installed on a web server running PHP and MySQL. Detailed installation instructions can be found on the FileRun website.

### Can I customize the look and feel of FileRun?

Yes, FileRun allows users to customize the look and feel of the interface using themes, as well as by editing the CSS and HTML code.

### Is FileRun compatible with different operating systems?

Yes, FileRun is compatible with Windows, Mac, and Linux operating systems, and can be accessed from any device with a web browser.

### Is FileRun secure?

FileRun uses industry-standard security measures such as HTTPS, user authentication, and access control to ensure the security of your files. It also has options for user and group management, which allows for granular control over who has access to files and folders.
