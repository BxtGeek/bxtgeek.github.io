Are you a new Linux user feeling overwhelmed by the amount of information you need to learn? This article offers a roadmap to navigate the vast world of Linux resources, curated by a Linux enthusiast himself. Whether you want to delve into the command line, understand the architecture of the system, or customize your desktop, this guide has got you covered.

## Getting Started

- **[Arch Wiki](https://wiki.archlinux.org/)**: This comprehensive resource is a gold mine of information on everything Linux-related, regardless of the distribution you use. It offers in-depth explanations of various system components and functionalities.

- **[Linux Journey](https://linuxjourney.com/)**: This website offers a structured learning path, categorized into beginner, intermediate, and advanced topics. You can learn the basics of the command line, file management, processes, and more through interactive exercises and quizzes.

## Taking it a Step Further

- **[Linux From Scratch](https://www.linuxfromscratch.org/)**: For the truly adventurous, this project allows you to build your entire Linux system from scratch. It’s a time-consuming endeavor, but an excellent way to gain a deep understanding of how Linux works.

- **[The Linux Foundation](https://training.linuxfoundation.org/resources/?_sft_content_type=free-course)**: This organization offers free courses on various Linux topics, from open-source licenses to cybersecurity. It provides a structured learning environment perfect for beginners.

## Learning the Command Line

- **[Linux Survival](https://linuxsurvival.com/)**: This website offers a step-by-step guide to navigating the command line, perfect for those new to the concept.

- [**Linux Command**](https://linuxcommand.org/): This website serves as a reference point for various command-line tools. You can learn about specific commands and even write shell scripts.

## Going Deep with YouTube Channels

- [**Learn Linux TV**](https://www.youtube.com/@LearnLinuxTV): This popular channel offers a vast collection of Linux tutorials and reviews. You can find in-depth explanations of various tools and commands.

- [**Veronica Explains**](https://www.youtube.com/@VeronicaExplains): This up-and-coming channel provides valuable lessons on specific command-line utilities and general Linux concepts.

## Sharpening Your Skills

- [**Terminus**](https://web.mit.edu/mprat/Public/web/Terminus/Web/main.html): This interactive game puts your command-line skills to the test in a fun and engaging way.

- **[Command Challenge](https://cmdchallenge.com/)**: This website offers practical exercises to test your understanding of specific commands.

## Customizing Your Desktop

- **Desktop Environment Help Pages**: Most desktop environments have built-in help sections that provide guidance on using the interface effectively.

- **[KDE User Base Wiki](https://userbase.kde.org/Welcome_to_KDE_UserBase)**: This wiki offers a comprehensive collection of guides on customizing the KDE Plasma desktop.

- **[Linux Scoop Channel](https://www.youtube.com/channel/UCNnUnr4gwyNmzx_Bbzvt29g)**: This YouTube channel provides tutorials on customizing desktops like GNOME and KDE by installing themes, extensions, and widgets.

- **[Unix Porn on Reddit](https://www.reddit.com/r/unixporn/)**: This subreddit showcases beautifully customized desktops, primarily using tiling window managers, for design inspiration.

## Gaming on Linux

- **[Gaming on Linux](https://www.gamingonlinux.com/)**: This website is your one-stop shop for everything Linux gaming-related. Stay updated on the latest news, discover how well specific games run on Linux, and learn about Proton compatibility.

- **[Proton DB](https://www.protondb.com/)**: This database lets you see if a particular Steam game runs on Linux using Proton, a compatibility layer.

## Staying Informed

- **[DistroWatch](https://distrowatch.com/)**: This website keeps you updated on the latest Linux distributions and their releases.

- **[Phoronix](https://www.phoronix.com/)**: This website focuses on Linux hardware reviews and benchmarks, providing valuable insights for gamers and enthusiasts.

- **[OMG Ubuntu & OMG Linux](https://www.omgubuntu.co.uk/)**: These websites offer news and information about Linux and open-source software.

- **[CorpIT Weekly Linux News](https://corpit.org/category/weekly-linux/)**: Stay updated on the latest Linux updates with your weekly news.

## Conclusion

This curated list is just a starting point for your Linux journey. Don’t hesitate to explore other resources and online communities. Remember, the most important aspect is to find a learning method that suits your style and keep practicing!
