Setting up Nginx Proxy Manager with Cloudflare for your homelab ensures that your services are secure, accessible, and easy to manage. This guide will take you through purchasing a domain, setting up Cloudflare, configuring an LXC container on Proxmox, installing NGINX Proxy Manager using Docker Compose, and configuring DNS and SSL.

#### 1\. **Buy the Domain**

The first step is to acquire a domain name. Follow these instructions:

- Choose a domain registrar (such as Namecheap, GoDaddy, or Google Domains).

- Search for an available domain name that fits your homelab.

- Purchase the domain and ensure you have access to its DNS settings.

_Tip:_ Selecting a descriptive domain name makes it easier to identify and manage your homelab services.

#### 2\. **Setting Up the Domain with Cloudflare**

Cloudflare enhances security and performance for your homelab by providing features like DNS management and SSL certificates. To set up Cloudflare:

- Create an account at [cloudflare.com](https://www.cloudflare.com).

- Add your domain to Cloudflare by entering its name and clicking **Add Site**.

- Cloudflare will automatically scan and import existing DNS records. Confirm that these records are accurate.

- Choose a suitable plan (the free plan is often enough for homelab setups).

- Update the nameservers at your domain registrar to point to the Cloudflare nameservers.

_Note:_ DNS changes may take a few hours to propagate.

#### 3\. **Setting Up the LXC Container Using Proxmox**

Proxmox is an excellent platform for managing virtual machines and LXC containers. Follow these steps to set up an LXC container:

- Log in to the Proxmox web interface.

- Navigate to **Datacenter > Node > Create CT**.

- Enter container details like hostname and password, and select a Linux template (e.g., Ubuntu Server).

- Allocate resources such as CPU, RAM, and storage according to your requirements.

- Complete the setup, and start the container once it's created.

_Tip:_ A lightweight Linux distribution is ideal for hosting NGINX Proxy Manager.

#### 4\. **Install Docker and Create NGINX Proxy Manager Using Docker Compose**

Once your LXC container is ready, you need to install Docker and set up NGINX Proxy Manager:

- SSH into your LXC container.

- Install Docker using the following commands:

```
  sudo apt update
  sudo apt install docker.io docker-compose -y
```

- Create a directory for NGINX Proxy Manager:

```
  mkdir nginx-proxy-manager && cd nginx-proxy-manager
```

- Create a `docker-compose.yml` file with the following content:

```
  version: '3'
  services:
    app:
      image: 'jc21/nginx-proxy-manager:latest'
      restart: always
      ports:
        - '80:80'
        - '81:81'
        - '443:443'
      environment:
        DB_MYSQL_HOST: "db"
        DB_MYSQL_PORT: 3306
        DB_MYSQL_USER: "npm"
        DB_MYSQL_PASSWORD: "npm_password"
        DB_MYSQL_NAME: "npm"
      volumes:
        - ./data:/data
        - ./letsencrypt:/etc/letsencrypt
    db:
      image: 'mariadb:latest'
      restart: always
      environment:
        MYSQL_ROOT_PASSWORD: 'root_password'
        MYSQL_DATABASE: 'npm'
        MYSQL_USER: 'npm'
        MYSQL_PASSWORD: 'npm_password'
      volumes:
        - ./db:/var/lib/mysql
```

- Save the file and run Docker Compose:

```
  docker-compose up -d
```

_Note:_ Make sure to replace passwords with your desired secure values.

#### 5\. **Login into the NGINX Proxy Manager**

After installing NGINX Proxy Manager, access it via a web browser:

- Open a browser and navigate to `http://<container-ip>:81`.

- Use the default login credentials:

- **Email:** `admin@example.com`

- **Password:** `changeme`

- After logging in, update the email address and password.

#### 6\. **Setting Up the DNS Record for the Homelab**

Configuring DNS records in Cloudflare will allow external traffic to reach your homelab:

- Log in to your Cloudflare dashboard.

- Go to the **DNS** section and add an **A** record.

- **Name:** (e.g., `homelab`)

- **IPv4 Address:** Your homelab’s public IP address.

- Enable **Proxy Status** (orange cloud icon) to route traffic through Cloudflare.

_Tip:_ Make sure port forwarding is set up on your router to direct traffic from your public IP to the LXC container.

#### 7\. **Setting Up the SSL Certificate in the NGINX Proxy Manager**

Securing your services with SSL is crucial. Here's how to do it using NGINX Proxy Manager:

- In the NGINX Proxy Manager dashboard, navigate to **SSL Certificates**.

- Click **Add SSL Certificate** and select **Let's Encrypt**.

- Enter your domain name and enable **Force SSL**.

- Complete the setup to automatically generate and renew SSL certificates.

#### 8\. **Adding the First Proxy Host in the NGINX Proxy Manager**

Now that everything is set up, you can add your first proxy host:

- Go to the **Hosts** section and click **Add Proxy Host**.

- Enter the **Domain Name** (e.g., `homelab.yourdomain.com`).

- Set the **Forward Hostname/IP** and **Forward Port** to match your internal service.

- Enable the **Force SSL** option and choose the SSL certificate you set up earlier.

- Click **Save** to activate the proxy host.

_Note:_ Repeat these steps to add more services to your homelab as needed.
