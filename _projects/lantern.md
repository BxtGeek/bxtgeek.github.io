A tiny self-hosted start page with no database and no npm dependencies. It runs
in one small container (Docker or Podman) and keeps everything in a single data folder.

- Service tiles with an icon picker (180 bundled app logos, emoji or your own image)
- Bookmarks, search with a switcher (DuckDuckGo, Google, Brave, Kagi, SearXNG and more)
- Weather and air quality from Open-Meteo, with no API key needed
- Built-in wallpapers, random Pexels or Unsplash photos, and your own uploads
- JSON export and import for backups
