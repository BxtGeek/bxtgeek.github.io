Stash grew out of SaveTheMovie. It tracks what you want to watch or read across
three categories, and all API keys stay server-side.

- Movies and TV (TMDb), anime (Jikan) and books (Google Books) in one place
- Watchlist and Watched lists for each category, stored in PostgreSQL
- Trending content per category and cross-source search
- React, TypeScript, Vite, Tailwind CSS and an Express backend
- One `docker compose up` to run the app and the database

*Vibe coded: built mostly with AI assistance.*
